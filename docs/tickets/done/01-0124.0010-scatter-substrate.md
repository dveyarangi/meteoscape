# Scatter substrate

- **Status:** Done (2026-08-21)
- **Type:** AFK
- **Plan:** [Scatter substrate RFC](../../rfc/done/01-0124.0010-scatter-substrate.md) — four green stages:
  origin identity + run-free origins, `ScatterDomain`, `origins()` across the capability forms,
  binder guards.
- **Blocks:** [Mongo obs source station serving](../01-0124.0020-mongo-obs-serving.md) — every piece
  here is a declared contract that source builds on.
- **Outcome:** The algebra can declare a station-scatter reach and pair it with declared
  provenance: `ScatterDomain` admits exactly its member points, `AtomicOrigin` carries optional
  identity (authority / process / unit), `Capability.origins` publishes (sub-domain, origin) pairs
  ahead of any request, an observation-shaped origin carries no run identity and never expires,
  and the binder accepts a storeless non-materialized producer under the re-stated policy guards.

## Parent

First slice of the [Mongo obs source](../01-0124-mongo-obs-source.md), which holds every align
resolution (2026-08-21) this slice implements; the parent keeps the union of criteria and the
serving work goes to [its second slice](../01-0124.0020-mongo-obs-serving.md). Carved on the
[0116](./01-0116-composition-lifetime.md) precedent: the contract lands fake-tested, ahead of
its first holder, so the holder does not invent it.

## What to build

The parent's resolved contracts, with no Mongo anywhere:

- **`ScatterDomain`** ([glossary](../../glossary.md)): a plain `Domain` whose `matches` is joint X/Y
  membership over paired `points` (exact admission, no epsilon), with per-axis T/Z. Not
  `EnumerableDomain` — conformance waits for the first scatter-shaped Coverage. Geometry only:
  no `Site` type, no labels; identity travels as declared provenance.
- **Origin identity** per [ADR-0003](../../adr/0003-provenance-and-origin.md)'s amendment: optional
  `authority` / `process` / `unit` on `AtomicOrigin`, default absent; `unit` is the instance's
  meaningful identity in the authority's namespace, never request-derivable.
- **Declared provenance** — the amendment's declaration side: `Capability.origins(parameter)`
  returns (sub-domain, `AtomicOrigin`) pairs over the reach, empty by default;
  `GranularCapability` gains an optional declared-origins source, `UnionCapability` concatenates
  its members', `DerivedCapability` and `EnumerableCapability` answer empty.
- **Run-free origins**: `issue_time` becomes optional (ADR-0003 already says an observation is
  run-free) and `expiration` takes a named never-expires sentinel. The blend `min` fold that makes
  a corrected value inherit its forecast parent's freshness is *not* built here — `SyntheticOrigin`
  is a fieldless stub with no constructor call in the tree, and its first real minting
  ([forecast correction](../01-0142-forecast-correction.md)) tests that property with its first
  consumer.
- **Binder loosening** ([#37](../../concerns.md#37-storeless-materialized-producers-and-read-back-homogenization)):
  a storeless non-materialized producer composes; the mirror-waste (materialized-with-store)
  refusal stays an unchanged error — unreachable outside fakes until #37's own trigger, the first
  real materialized provider, which owns any loosening. The metered-uncached refusal is
  deliberately absent — metered is a **provider property** with no declaration yet;
  [0130](../01-0130-vendor-call-ledger.md) mints `ProviderManifest.metered` and restores it, and
  the removed guard carries a TODO naming that.

## Acceptance criteria

- [x] A `ScatterDomain` admits a request at a member point and declines a cross-combination of one
      point's longitude with another's latitude — pinned by a test naming the joint-membership rule.
- [x] `AtomicOrigin` carries `authority` / `process` / `unit` when given and defaults to all-absent;
      every existing provenance test passes unchanged.
- [x] A capability declaring per-station origins publishes (sub-domain, origin) pairs whose
      coordinates and identities are readable together before any request — fake-tested against a
      scatter capability; undeclaring forms (`DerivedCapability`, `EnumerableCapability`, an
      unbound `GranularCapability`) answer empty, and `UnionCapability` concatenates its members'.
- [x] An `AtomicOrigin` with no `issue_time` and never-expiring `expiration` constructs and
      serves; every existing consumer of `issue_time` is unaffected (all existing tests pass
      unchanged).
- [x] `wire_source` composes a storeless non-materialized producer; the materialized-with-store
      refusal stays an unchanged error (unreachable outside fakes until the first real
      materialized provider — [#37](../../concerns.md#37-storeless-materialized-producers-and-read-back-homogenization)'s
      own trigger owns any loosening); the removed refusal site carries a TODO naming
      [0130](../01-0130-vendor-call-ledger.md) as where `ProviderManifest.metered` restores the
      metered-uncached guard.

## Out of scope

- Any Mongo code, fixture, or dependency → [second slice](../01-0124.0020-mongo-obs-serving.md).
- Edge narration of stations (the MCP `_t_extent` fold's non-separable raise) — no public profile
  serves a scatter reach; the branch lands with the surface that needs it
  ([embedding surface](../01-0125-supported-python-embedding.md) or later).
- Composing a scatter reach beside a forecast reach over one parameter →
  [obs+forecast reach composition](../01-0137-obs-forecast-reach-composition.md).
