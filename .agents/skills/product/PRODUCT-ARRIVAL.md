# What the product document says before anything is decided

Machine input for the install, read by nobody at session time: a tree that has the product
mechanism keeps a product document, and one that has just received core has decided nothing to
put in it. The words are this mechanism's, because the document is; `product.py` writes them and
the install only calls it.

Written only where no file is at the document's path, on an install or an update. From its first
line the document is the project's — nothing merges it, nothing overwrites it, and one already
there in another form is left as it stands.

```product-document
# What this project is for

- **record of** what must always hold

The project's account of what it is for, in the product format: the pains it relieves, the goals
it must not lose, the causes, and the answers. Nothing is decided yet; each answer lands here as a
row when a question under *What is this project for?* is decided.

## Goals

## Causes

## Answers

```
