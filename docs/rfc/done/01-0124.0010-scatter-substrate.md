# Scatter substrate — implementation plan

**Authored:** 2026-08-21
**Last amended:** 2026-08-21 (fourth validation pass)

Implements the [scatter substrate](../../tickets/done/01-0124.0010-scatter-substrate.md) slice of the
[Mongo obs source](../../tickets/01-0124-mongo-obs-source.md): the declared contracts that source will
hold, landed fake-tested ahead of it. No Mongo anywhere in this plan.

## Scope and boundaries touched

| Boundary | Owner | Change |
|---|---|---|
| `Domain` family (`manifold/domain.py`) | [ADR-0002](../../adr/0002-data-model.md) | new member `ScatterDomain`; no existing type changes |
| `AtomicOrigin` / provenance (`manifold/provenance.py`) | [ADR-0003](../../adr/0003-provenance-and-origin.md) origin-identity amendment | three optional identity fields; `issue_time` optional; never-expires constant |
| `Capability` protocol + four forms (`manifold/capability.py`) | ADR-0003 amendment, declaration side | new `origins()` member |
| `SourceBinder` (`nodes/composition.py`) | [#37](../../concerns.md#37-storeless-materialized-producers-and-read-back-homogenization) loosening, recorded in the parent ticket | biconditional → one refusal; build-time refusals live here |
| `wire_source` (`nodes/weaver.py`) | same | reads store presence as *storeless*, no longer as *materialized* |

The two rows are one change with two homes: the **refusal** is build-time and belongs to the
binder (`CompositionError`); `wire_source` only *reads* the resulting store presence.

Not touched: sampling's `GridDomain` gate, `Reservoir`, the MCP edge's `_t_extent`
(mcp_app.py:212 — no served profile carries a scatter reach until 0020, and that one is
Gateway-tested, not MCP-served), every provider, `SourceKey`, the reconciler folds
(→ [obs+forecast reach composition](../../tickets/01-0137-obs-forecast-reach-composition.md)).

## Shapes

The shapes below are the documented boundary; field *names* internal to a shape are local choices
unless shown.

### `ScatterDomain` — manifold/domain.py

```python
@dataclass(frozen=True)
class ScatterDomain(Domain):
    points: tuple[tuple[float, float], ...]   # paired (x, y); X/Y are never a product.
                                              # __post_init__ refuses empty and duplicate
                                              # points: a scatter is a SET of places (tuple is
                                              # order/hash only), and an empty declaration must
                                              # be *absence* — the parameter omitted from the
                                              # capability — never a vacuous domain that
                                              # declines everything while looking declared.
    t: Axis                                   # any Axis — the past-facing member is 0020's
    z: Axis

    def matches(self, other: Domain) -> bool:
        # X/Y jointly: other's X/Y position must equal some (points[i]); exact, no epsilon.
        # Request-side X/Y is either positional or boundless — a bounded spatial span is
        # unrepresentable (SnappedAxis bounds are temporal-only, domain.py:302). Positional
        # compares jointly; boundless (`ANY`) and multi-position (a box) both DECLINE —
        # intended v1 semantics, not a bug: "all stations" is the enumeration ask, noted-not-
        # designed at the align, impossible before a scatter-shaped Coverage exists.
        # T/Z: per-axis `matches` as everywhere (domain.py:113).
    def intersect(self, other: Domain) -> Domain:
        raise NotImplementedError              # same seam as every v1 domain
    # NO axis() method — Separable is a @runtime_checkable protocol whose sole member is
    # axis() (domain.py:413), so defining one would make the scatter FALSELY pass
    # as_separable and blow up per-axis machinery mid-flight instead of narrowing to None.
    # T/Z are plain fields; the scatter is jointly held, deliberately not Separable
    # (ADR-0002 non-separable default; #12's first occupant).
```

Plain `Domain`, not `EnumerableDomain` — conformance waits for the first scatter-shaped Coverage
and its sampler widening (ticket, Out of scope). Not `Separable` — `require_separable` callers
(reconciler, calculator folds) meeting a scatter is exactly 0137's territory and must keep
*failing* until it lands, not half-work through a hull.

### Origin identity — manifold/provenance.py

```python
@dataclass(frozen=True)
class AtomicOrigin(Origin):
    source: SourceKey
    issue_time: datetime | None          # None: run-free (observation) or declared (pre-fetch)
    authority: str | None = None         # who stands behind the values
    process:   str | None = None         # how they were made
    unit:      str | None = None         # which instance, in the authority's namespace

NEVER_EXPIRES: Final[datetime]           # module constant; the exact name is local.
                                         # MUST be tz-aware: the clock convention is aware UTC
                                         # (clock.py:16) and bare datetime.max is naive —
                                         # naive-vs-aware comparison raises TypeError.
```

`Provenance.expiration` stays a required `datetime`; an observation stamps the constant, and the
freshness read `expiration > now` (provenance.py:52, reservoir.py:127) is correct for it with no
consumer change. The blend `min` fold is **not** built here — `SyntheticOrigin` is a fieldless
stub with no constructor call in the tree; the inheritance property is 0142's to test with its
first blend.

### Declared provenance — manifold/capability.py

```python
class Capability(Protocol):
    ...existing members...
    def origins(self, parameter: ParameterId) -> Sequence[tuple[Domain, AtomicOrigin]]:
        """Declared provenance over the reach: each entry pairs a sub-domain with the origin
        that would serve it. Empty = nothing declared. An unserved parameter raises KeyError,
        mirroring reach() — both read the declaration; serves() alone answers softly.
        Declared entries lie within the reach (tested as a property on the fake): a
        declaration must not advertise what admission would refuse. ADR-0003, declaration side."""
```

Per form:

```python
GranularCapability     # gains one optional field, default None → origins() answers ()
                       #   the field holds per-parameter declared entries; exact field
                       #   name/shape (mapping vs callable) is a local choice — it is
                       #   provider-supplied data, not a boundary
EnumerableCapability   # origins() → ()   (until a materialized producer declares)
DerivedCapability      # origins() → ()   (synthetic identity is minted at calculation)
UnionCapability        # origins() → concatenation of members' entries for the parameter, in
                       #   member (bind) order, skipping members that do not serve it —
                       #   member.origins mirrors reach's KeyError, so the fold filters by
                       #   membership first; v1 profiles have one declarer at most
```

A declared origin's sub-domain is any `Domain`; the natural scatter entry is a one-point
`ScatterDomain` sharing the reach's T/Z — reusing the type rather than minting an entry shape.
A declared origin never carries `issue_time` (nothing fetched yet). **The pair type is forced,
not chosen**: `Provenance` requires `fetched_at` and `expiration` (provenance.py:56-58), which
exist only at fetch — so declarations carry bare `AtomicOrigin`, and a "declared `Provenance`"
is unrepresentable by construction. The declared == stamped
equality is **0020's** end-to-end criterion, where one `StationRecord` feeds both; this slice
proves the channel's shape with fakes.

### Binder loosening — nodes/composition.py

`store is None ⇔ materialized` (composition.py:38-51, 113-120) loosens as follows — resolved at the
first validation pass (2026-08-21), which caught the initially drafted keyed-as-metered proxy
being false on its first customer (`collector-obs` is keyed *and* unmetered; metered is a
**provider property**, never key-existence):

- the `elif store is None: raise` refusal for non-materialized producers is **removed** — a
  storeless non-materialized producer composes;
- the materialized-with-store refusal **stays an error, unchanged, in this slice** — #37 permits
  "at most a warning" but does not require one; the combination is unreachable outside test fakes
  until the first real materialized provider exists (#37's own trigger), and that arrival owns the
  loosening. Downgrading now would mint a warning mechanism (none exists in `src` — measured) for
  a case nothing can hit;
- the **metered-uncached refusal is deliberately absent from this slice**: "metered" has no
  declaration yet — [0130](../../tickets/01-0130-vendor-call-ledger.md) mints
  `ProviderManifest.metered` and restores the refusal. **Append a TODO comment at the removed
  guard naming exactly that** (temporary gap, flagged so nothing grows to rely on it). Between
  this slice and 0130 a misconfigured storeless vendor would compose and buy a call per request —
  a deliberate, marked interim in configuration we author.

Existing profiles compose byte-identically (every current offering declares a store or is
materialized).

## Stages (each ends green)

1. **Origin identity + run-free origins.** Add the three fields (defaults `None`) and make
   `issue_time` optional; add the never-expires constant. Tests: construction/defaults; a
   run-free never-expiring origin is fresh forever under the reservoir's freshness read; full
   existing suite passes untouched — the 11 existing `AtomicOrigin(` call sites are positional
   two-argument constructions (measured), which stay valid because every addition is a trailing
   defaulted field. `pyright` sweep confirms no consumer assumes `issue_time` non-None (measured
   ahead: no code reads `origin.issue_time` outside provenance itself; MCP never serializes it).
2. **`ScatterDomain`.** Joint `matches` (member point admits; cross-combination of one point's x
   with another's y declines — the test names the joint-membership rule), T/Z per-axis behavior,
   non-separability (`as_separable` → `None`, `as_enumerable_axes` → `None`), frozen/hashable
   equality on `points`, and construction refusal of empty and duplicate `points` (named tests:
   emptiness must be expressed as capability absence, and a duplicate place is a registry bug
   surfacing loudly, not a silent double entry).
3. **`origins()` across the four capability forms.** Protocol member (widening is type-time only —
   `Capability` is `@runtime_checkable` but zero `isinstance` sites exist, measured; the three
   `GranularCapability(` sites construct by keyword). Fake scatter capability publishes paired
   entries, including the docstring's **within-reach property**, checked structurally (every
   entry's points appear among the reach's points; T/Z extents within the reach's) — a
   declaration must not advertise what admission refuses, and the check is containment of
   declared data, not a `matches()` call between two declared domains (that direction is
   requester-shaped and stays unbuilt). Unbound `GranularCapability`, `DerivedCapability`,
   `EnumerableCapability` answer empty; an **unserved** parameter raises `KeyError` on every form
   (named test — the empty-vs-KeyError split is the docstring's promise: served-but-undeclared is
   empty, unserved is an error, mirroring `reach`); `UnionCapability` concatenates in bind order,
   skipping non-serving members. Test fakes reuse the real capability forms (fakes.py imports
   `GranularCapability` / `EnumerableCapability` — measured), so the concrete implementations
   cover the suite; any residual hand-rolled structural fake gains the empty answer — an expected
   near-empty sweep.
4. **Binder guards.** Remove the non-materialized-storeless refusal, appending the 0130 TODO at
   the removed site as above; the materialized-with-store error and its existing test stay
   byte-identical; the "missing store shape" guard test flips into the new test that a storeless,
   non-materialized producer composes.

Stage order: 1 unblocks 3; 2 and 4 are independent. No stage leaves tests red.
