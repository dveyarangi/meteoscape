## What to build

`manifold/domain.py` only (~100–140 raw lines; m2/003c-scale):

- `SnappedAxis.interval: Interval[datetime] | None` — the boundless form is `ANY`; the
  `SelectableAxis` union is unchanged. Temporal narrowing bites only when bounds are present; a
  boundless member is axis-generic (sits on Z). One-sided bounds stay unrepresentable (`Interval`
  requires both edges) → parent, *Request vocabulary*.
- Open member semantics: `matches` everything; no `extent`.
- `ground`'s third per-axis arm: a boundless member takes the answering axis whole.
- `RegularAxis.clip` gains the float boundary tolerance — index space, one branch-free expression
  for both coordinate kinds, one policy shared with `LATTICE_TOLERANCE` → parent, *quantize is
  ground's store-side sibling*.

Deliberately **not** here: `agreed_geometry` stays untouched — its group return arrives with the
carrier in the next slice, which owns both call sites. Nothing in-tree authors a boundless member
yet; the new paths are exercised by unit tests.
