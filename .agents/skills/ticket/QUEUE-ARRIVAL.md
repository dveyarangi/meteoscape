# What the queue says before anything has happened in it

Machine input for the install, read by nobody at session time: a tree that has just received
core has a queue to read and nothing to put in it. The words are this mechanism's, because the
queue is; the install places them and composes nothing.

Written only into a tree that has none, on an install or an update. From its first line the
record is that project's — nothing merges it, nothing overwrites it.
