## What to build

~250–350 raw lines (002b-scale):

- Mint the **multi-domain carrier**: a `Manifold` grouping single-domain Coverages; its own
  `project` folds onto a fully enumerable Selection (the retirement home of `_assemble` — closure
  preserved) → parent, *The carrier, and the fold that returns it*.
- `agreed_geometry` gains the open-axis licence: bounded axes must agree (permanent law),
  boundless members license per-record difference — validated by the fold, which keeps its single
  return (records carry their own domains; the differing resolutions have no reader). The fold's
  and the carrier's final names are chosen here (the edge record's naming checkpoint).
- Timeline wrapper rework: **retire both eager folds** — the Z flatten (`_assemble` at fetch) and
  the parameter crop (`_as_delivered`) — under the parent's one law: *the answer carries the
  provider's natural shape; the store absorbs it; the serve crops.*
- **Natural fetch unit**: the answer may carry more parameters than asked, never fewer;
  Open-Meteo's is its whole offering → parent, *Refill scope*;
  [#43](../../concerns.md#43-narrow-answering-providers-re-open-mixed-request-run-divergence).
  ADR-0001's answer-discipline sentence lands with this code.

## Acceptance criteria

- [x] Asked with boundless Z/T (direct provider test), the timeline answers **multi-domain** —
      records keyed by native Z (2 m, 10 m, surface, `[0,TOA]`) from a **single** vendor fetch.
- [x] Asked for a parameter subset, the answer carries the whole offering (natural fetch unit); an
      enumerable ask still yields one co-domained Coverage (closure).
- [x] Projecting the carrier with a fully enumerable Selection reproduces today's folded answer.
- [x] Every live path is behavior-identical: the full existing suite passes unchanged; the eager
      folds' retirement is observable only to direct callers asking `ANY`.
- [x] The edge record's naming checkpoint is closed — the chosen fold and carrier names are
      recorded there.

## Landed beyond the plan

The review after implementation added three statements to the
[provider edge record](../../edge/provider.md) that the RFC had left
underspecified, and no code behaviour changed for any of them:

- The sampler's `NotImplementedError` is an **internal assert** that `serves` over-promised
  ([#21](../../concerns.md#21-serves-extent-vs-project-crop-ability)), a fourth outcome deliberately
  outside the leaf taxonomy — never translated into `CapabilityMismatch`, which would collapse it into
  [#36](../../concerns.md#36-unserved-and-uncomparable-are-indistinguishable)'s conflation.
- **Pinned Z and vantage Z are different promises**, and a vantage relabel is an **∃-claim** — the same
  rule the store owns at [#25](../../concerns.md#25-root-store-holding-reuse-across-vantage-windows),
  second site.
- The **natural fetch unit is unwitnessed, not deferred**: a wrapper constant binding every timeline
  vendor, with 011 as the witness that decides whether a per-offering declaration is owed
  ([#43](../../concerns.md#43-narrow-answering-providers-re-open-mixed-request-run-divergence)).

One caveat for slice 4: the parameter widening is **inert** until a store exists to hold the surplus,
so "behaviour-identical" here is a statement about a path nothing yet walks.
